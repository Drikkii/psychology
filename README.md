# psychology

Проект по психологии. Статический сайт на GitHub Pages, без сервера.

🌐 **Сайт:** https://drikkii.github.io/psychology/

## Структура

```
index.html     — главная страница
css/style.css  — стили
js/main.js     — скрипты
.nojekyll      — отключает обработку Jekyll на GitHub Pages
```

## Деплой

Сайт публикуется из ветки `gh-pages`. Чтобы обновить сайт, достаточно запушить изменения в эту ветку:

```bash
git push origin gh-pages
```

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический сервер, например:

```bash
npx serve .
```
