# Сайт психолога Юлии Шевченко

**[psycholog.now](https://psycholog.now)** — сайт частного психолога, который консультирует онлайн на русском языке.
Задача — чтобы клиент быстро понял, с чем психолог работает, сколько это стоит, и написал в удобный мессенджер.

Сайт сделан с нуля, без конструкторов и CMS: статический HTML + своя админка на Node.js, в которой психолог сама
меняет тексты, цены, отзывы и пишет статьи — без программиста.

> В этом репозитории — **готовый сайт** (то, что видит посетитель). Генератор страниц и админка — в закрытой части
> проекта: в них работа с паролями и данными клиентов, поэтому их код здесь не публикуется.

## Что умеет сайт

- **Главная** со слайдером (свайп, бесконечная лента, автопрокрутка), блоки «С чем я работаю», «Как начать», отзывы.
- **Услуги и цены**: карточки услуг со скидками, пакеты консультаций — цена в рублях и сразу примерно в долларах,
  экономия считается автоматически; частые вопросы.
- **Обо мне**: история, подход, карусель дипломов и сертификатов с полноэкранным просмотром.
- **Отзывы**: форма «Написать отзыв» с модерацией (на сайт попадает только одобренное) и отзывы с внешней площадки.
  Обе ленты листаются свайпом и стрелками и сортируются по дате отзыва.
- **Статьи**: список и страницы статей, обложки, подпись автора, разметка для поисковиков.
- **Документы**: Политика конфиденциальности и Условия консультаций.
- **Тёмная тема**, адаптив от 320 px до широких экранов, кнопки связи с любого экрана.

## Админка (закрытая часть)

Своя админ-панель без фреймворков — психолог работает в ней сама:

- разделы: слайдер, главная, услуги и пакеты, контакты, «Обо мне», отзывы, статьи, документы, статистика;
- **предпросмотр** любого изменения на телефоне и ПК до публикации, затем сайт пересобирается за пару секунд;
- **редактор статей**: заголовки, списки, цитаты, картинки с подписями, черновики;
- загрузка фото с автоматическим сжатием в WebP и нарезкой размеров для телефона и ПК;
- **история версий** текстов (100 последних) и скачивание полного бэкапа одной кнопкой;
- **статистика**: свой счётчик посещений без cookie + Яндекс Метрика и Google Analytics в одном разделе;
- модерация отзывов: новые приходят «на одобрение» с отметкой в меню.

## Технологии

| Часть | Что использовано |
|---|---|
| Сайт | HTML, CSS, ванильный JavaScript — без фреймворков и сборщиков |
| Генератор страниц | Node.js: тексты лежат в одном JSON, скрипт собирает из них все страницы, `sitemap.xml`, `robots.txt`, `llms.txt` |
| Админка | Node.js без фреймворков (встроенный `http`), единственная зависимость — `sharp` для обработки фото |
| Хостинг | обычный shared-хостинг с cPanel: Apache + Passenger для Node-приложения, бэкапы по расписанию |

Почему так: статический сайт быстрый, дешёвый в хостинге и почти не ломается, а админка нужна только психологу —
поэтому никакой базы данных и CMS, всё в одном JSON-файле, который легко бэкапить и переносить на другой сервер.

## Скорость, SEO и доступность

- **Lighthouse (телефон):** производительность 99, рекомендации 100, специальные возможности 96
  (найденное замечание — порядок заголовков — исправлено до запуска).
- Картинки в WebP с `srcset`, ленивая загрузка, css/js с отпечатком версии в адресе, gzip и долгий кеш.
- **SEO:** у каждой страницы свой title и description, один `h1` (в том числе после JS — у копий слайдов в карусели
  заголовок становится `h2`), canonical, Open Graph, sitemap с реальными датами изменения, редиректы на https и без www.
- **Структурированные данные** (Schema.org JSON-LD одной связанной «картой»): специалист и услуги с ценами, FAQ,
  статьи с автором, хлебные крошки, профиль.
- **ИИ-поиск:** `llms.txt` с выжимкой о сайте, явный доступ для ИИ-ботов в `robots.txt`.
- **Доступность:** правильные роли у карусели, подписи у всех кнопок и полей, переход к содержанию с клавиатуры,
  порядок заголовков.

## Безопасность и приватность

- Строгая **Content Security Policy**: на страницах выполняются только свои скрипты и явно разрешённые счётчики.
- **Аналитика только после согласия** на плашке cookie; при отзыве согласия cookie счётчиков удаляются.
  Вебвизор, рекламные функции и персонализация отключены.
- Админка: пароль хранится только как хеш **scrypt** с солью, защита от подбора (блокировки по IP и логину),
  CSRF-токены и проверка Origin, сессии привязаны к паролю — смена пароля выбрасывает всех.
- Заголовки безопасности (HSTS, nosniff, Referrer-Policy, X-Frame-Options, Permissions-Policy).
- В репозиторий не попадают ключи, данные клиентов и исходники документов: это проверяет git-хук перед каждым коммитом.

## Структура репозитория

```
index.html, services.html, about.html, contacts.html   — страницы (собраны генератором)
articles.html, article-*.html                           — список статей и статьи
privacy.html, terms.html, 404.html                      — документы и своя страница 404
css/style.css                                           — все стили, светлая и тёмная тема
js/main.js                                              — слайдер, карусели, меню, cookie, счётчики
js/config.js                                            — публичные настройки (номера счётчиков)
js/theme-init.js                                        — тема до отрисовки, без вспышки
img/                                                    — фото в WebP (+ размеры 640 и 1080 для слайдов)
.githooks/pre-commit                                    — не даёт закоммитить ключи и личные файлы
```

Страницы в этом репозитории **не правятся руками** — их пересобирает генератор из админки.
Индексация этой копии отключена (`noindex`): в поиске должен быть только основной домен.
